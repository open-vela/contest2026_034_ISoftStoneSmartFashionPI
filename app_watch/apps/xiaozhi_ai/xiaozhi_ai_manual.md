# 小智AI - 用户使用手册

## 应用简介

小智AI是一款运行在智能手表上的AI对话助手应用，通过WebSocket安全连接到小智AI云端服务，支持语音和文字两种交互模式。

## 界面布局

```
+---------------------------+
|  <    待命    =            |  <- 顶部状态栏（返回/标题/菜单）
|                           |
|      [语音模式]           |  <- 音频模式标签
|                           |
|         +-----+           |
|         | O O |           |  <- 笑脸图标（动态表情）
|         |  )  |           |
|         +-----+           |
|                           |
|   Hi! 有什么可以帮到你呢？  |  <- 状态/问候文字
|     语音功能暂不可用       |  <- 副标题提示
|                           |
|   +-------------------+   |
|   |                   |   |
|   |   对话消息区域     |   |  <- 对话区域（连接后显示）
|   |                   |   |
|   +-------------------+   |
|                           |
|   +-------------------+   |
|   |     开始对话       |   |  <- 操作按钮
|   +-------------------+   |
+---------------------------+
```

## 笑脸表情说明

应用中的笑脸图标会根据当前状态自动切换表情：

| 表情 | 状态 | 说明 |
|------|------|------|
| 微笑 | 待命 / 已连接 | 表示应用就绪，可正常使用 |
| 中性 | 连接中 | 表示正在与服务器建立连接 |
| 难过 | 连接失败 | 表示出现错误，需要处理 |

## 应用状态

### 待命状态
- 显示微笑表情和问候语
- 操作按钮显示"开始对话"
- 点击"开始对话"进入连接流程

### 连接中
- 显示中性表情
- 操作按钮显示"取消"
- 正在与服务器建立WebSocket安全连接
- 点击"取消"可中止连接

### 已连接
- 显示微笑表情和"小智已就绪"
- 操作按钮显示"断开连接"
- 对话区域出现，显示AI回复的消息
- 语音模式：可说话与AI对话
- 文字模式：等待AI回复
- 点击"断开连接"返回待命状态

### 连接失败
- 显示难过表情和错误信息
- 操作按钮显示"重试"
- 常见错误：WiFi未连接、服务器不可达
- 点击"重试"重新连接

## 交互操作

| 操作 | 说明 |
|------|------|
| 点击操作按钮 | 根据当前状态执行对应操作 |
| 右滑手势 | 退出应用，返回桌面 |
| 点击左上角"<" | 退出应用，返回桌面 |
| 对话区域滚动 | 查看历史消息 |

## 前置条件

- **WiFi连接**：使用小智AI前，请确保手表已连接WiFi网络
- **网络可用**：需要能访问 `api.tenclass.net` 服务器
- **音频硬件**：语音模式需要设备支持I2S音频（ES8311芯片）

## 通信协议

- 传输协议：WSS（WebSocket over TLS）
- 服务器地址：`api.tenclass.net:443`
- 路径：`/xiaozhi/v1/`
- 音频格式：Opus编码，16kHz采样率，单声道
- 帧时长：60ms

## 故障排除

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| "请先连接WiFi" | WiFi未连接 | 在设置中连接WiFi |
| "无法连接到小智服务器" | 网络不可用 | 检查WiFi信号，确认网络通畅 |
| "连接已断开" | 网络中断 | 检查网络连接后重试 |
| "语音功能暂不可用" | 硬件不支持 | 使用文字模式，或确认设备音频配置 |
| 连接超时 | 服务器响应慢 | 稍后重试 |

## 技术架构

- **UI框架**：LVGL v9.1.0
- **网络通信**：mbedtls SSL/TLS + WebSocket RFC 6455
- **运行平台**：OpenVela (NuttX RTOS) on ESP32-S3
- **屏幕分辨率**：410x502 竖屏
